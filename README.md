# 🤖 AI Smart Attendance System

An automated, user-friendly attendance management system built with Python and Streamlit, designed to simplify student registration, face-scan log tracking, and real-time attendance analytics in a clean light theme interface.

🔗 **Live Demo:** [Click Here to Access Streamlit App](https://aismartattendance.streamlit.app)

---

## ✨ Key Features

* **📷 Automated Attendance Marking:** Instant attendance logging with live camera capture—no extra clicks needed.
* **⚙️ Integrated Admin Control Panel:** Direct Home Screen access (2-column layout) to register new students and manage records without sidebar navigation.
* **📚 Subject-wise Tracking:** Dropdown support for subject selection during attendance marking.
* **📧 Email Confirmations:** Automated email notifications sent to students upon successful attendance logs via SMTP.
* **📊 Analytics & Percentage Breakdown:** Visual representation of attendance metrics and subject breakdowns powered by Plotly.
* **📥 PDF Report Export:** Instant generation and downloading of official attendance summary reports.
* **🎨 Clean Light Theme:** Styled with custom CSS overrides for consistent visual clarity.

---

## 🛠️ Tech Stack

* **Language:** Python 3.14
* **Framework:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Plotly Express
* **Document Generation:** FPDF
* **Deployment:** Streamlit Cloud & GitHub
